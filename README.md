# Jav Claw

Jav Claw 是一款Nas小姐姐收藏的桌面工具。它可以扫描本地文件夹或 NAS 目录，自动识别影片番号，刮削影片信息、封面、演员、标签等资料，并生成媒体服务器可识别的整理结果。

适合用来把零散的视频文件整理成更清晰的资料库，方便在 Jellyfin、Emby、Kodi 等媒体库中浏览和管理。

## 主要功能

- 扫描本地文件夹或 WebDAV/NAS 目录
- 自动识别文件名中的影片番号
- 批量刮削影片标题、封面、演员、标签、发行日期等信息
- 自动生成 NFO 文件
- 下载封面图和背景图
- 按番号或演员分类整理文件
- 支持刮削暂停、继续、停止
- 支持扫描取消和进度显示
- 支持多个刮削源，来源可在设置中选择和排序

## 使用流程

### 1. 选择资源位置

打开软件后，先选择资源所在位置：

- 本地目录：适合直接整理 Mac/Windows 上的文件夹，或已经挂载到系统里的 NAS 目录。
- WebDAV：适合通过 WebDAV 直接连接远程 NAS。

如果使用 WebDAV，需要先填写服务器地址、账号和密码，并测试连接。

### 2. 扫描视频文件

进入文件浏览页面后，选择要整理的目录，然后开始扫描。

扫描过程中会显示当前进度。  
如果目录选错了，或者扫描时间太长，可以随时取消扫描。

扫描完成后，软件会列出识别到番号的视频文件。

### 3. 设置整理方式

在开始刮削前，建议先进入设置页面确认：

- 刮削源：选择要使用的数据源，默认建议全部勾选。
- 刮削源顺序：排在前面的来源会优先使用。
- 整理模式：可以按番号整理，也可以按演员分类。
- 是否生成 NFO：建议开启。
- 是否下载封面和背景图：建议开启。
- 代理设置：如果部分数据源无法访问，可以填写 HTTP 代理。

### 4. 开始刮削

回到刮削页面后，点击开始刮削。

刮削过程中，每个视频都会显示当前状态。成功后会展示封面、标题、演员、标签、日期等信息。

如果设置了整理完成目录，软件会自动：

- 创建整理后的文件夹
- 保存 NFO 文件
- 下载封面和背景图
- 移动原视频文件
- 清理源目录中的残留文件和空目录

### 5. 检查结果

刮削完成后，可以到整理完成目录查看结果。

通常每部影片会包含：

- 原视频文件
- NFO 信息文件
- `poster.jpg` 封面
- `fanart.jpg` 背景图

把整理后的目录加入 Jellyfin、Emby 或 Kodi 媒体库后，媒体服务器就可以读取这些资料。

## 文件整理方式

### 按番号整理

每部影片会放入独立文件夹，例如：

```text
整理完成/
  SONE-031/
    SONE-031.mp4
    SONE-031.nfo
    poster.jpg
    fanart.jpg
```

### 按演员整理

影片会先按主要演员分类，再放入影片文件夹，例如：

```text
整理完成/
  演员名/
    SONE-031/
      SONE-031.mp4
      SONE-031.nfo
      poster.jpg
      fanart.jpg
```

## 常见问题

### 有些影片识别不到怎么办？

可以检查文件名里是否包含清晰的番号。  
建议使用类似 `SONE-031.mp4`、`FC2-PPV-1234567.mp4` 这样的命名方式。

### 有些影片刮削不到资料怎么办？

可能是当前刮削源没有收录，或者网络暂时无法访问。  
可以在设置中启用更多刮削源，调整优先级，或配置代理后重试。

### 封面显示失败怎么办？

部分图片站点会限制直接访问。软件会优先使用已下载到本地的封面；如果还没有保存，会尝试通过内置方式加载远程图片。  
如果仍然失败，可以重新刮削，或检查网络和代理设置。

### WebDAV 整理速度慢怎么办？

远程 NAS 的扫描、下载和移动速度会受到网络影响。  
如果文件很多，建议先整理较小目录，确认流程正常后再批量处理。

### 会删除我的视频吗？

整理时软件会把视频移动到整理完成目录。  
如果开启自动清理，源目录中没有视频后，软件会清理残留文件和空目录。建议首次使用时先用少量文件测试，确认整理结果符合预期。

## 使用建议

- 首次使用先选择一个小目录测试。
- 文件名尽量保留完整番号。
- 刮削源默认全部勾选即可。
- 整理前确认输出目录是否正确。
- 使用 WebDAV 时，先确认 NAS 连接稳定。
- 如果要给媒体服务器使用，建议开启 NFO、封面和背景图下载。
